FULL SUITE UPDATE

1. Stop the current Self Service Portal command window/service.
2. Back up the existing C:\SelfServiceSuite folder.
3. Extract this ZIP and copy the included SelfServiceSuite folder to C:\SelfServiceSuite.
4. Keep the server's working .env values if they are different from the included .env.
5. Publish the Business Central app using the commands below.
6. Start the Self Service Portal again.
7. In the browser press Ctrl+F5 once.

BUSINESS CENTRAL PUBLISH COMMANDS
---------------------------------
Run Windows PowerShell as Administrator:

Import-Module "C:\Program Files\Microsoft Dynamics 365 Business Central\240\Service\NavAdminTool.ps1"

Publish-NAVApp `
  -ServerInstance BC240 `
  -Path "C:\SelfServiceSuite\SelfServiceBackend\deploy\Technology Associates EA Ltd_BC24_TA App_1.0.2.936.app" `
  -SkipVerification `
  -Force

Sync-NAVApp `
  -ServerInstance BC240 `
  -Tenant default `
  -Name "BC24_TA App" `
  -Version "1.0.2.936" `
  -Mode Add

Start-NAVAppDataUpgrade `
  -ServerInstance BC240 `
  -Tenant default `
  -Name "BC24_TA App" `
  -Version "1.0.2.936"

VERIFY THE INSTALLED VERSION
----------------------------
Get-NAVAppInfo -ServerInstance BC240 -Tenant default -Name "BC24_TA App" |
  Format-Table Name, Version, IsInstalled

Expected: Version 1.0.2.936 and IsInstalled True.
