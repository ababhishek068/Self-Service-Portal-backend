NETWORK ERROR ON LOGIN — FIXED IN v1.0.3.51
============================================

Cause: Portal was calling http://localhost:4000 while you open
       http://10.30.4.23:4000 → browser blocks → "Network Error".

Fix: Rebuilt with on-prem mode (no localhost baked in).
     Portal now uses the SAME address you type in the browser.

IMMEDIATE WORKAROUND (no redeploy — try this first):
1. On login page press F12 → Console
2. Paste and Enter:
   localStorage.setItem('ssp.apiBaseUrl', window.location.origin)
3. Ctrl+F5 refresh → login again

FULL FIX (redeploy public/ only):
1. Stop portal (Ctrl+C in CMD window)
2. Copy ONLY public\ folder from this zip to:
   C:\TA\SelfServiceSuite\SelfServiceBackend\public\
3. Copy dist\ folder too (v1.0.3.51)
4. Keep your existing .env — do NOT overwrite
5. START-HIJRA-PORTAL.bat
6. Ctrl+F5 in browser
7. Check http://10.30.4.23:4000/api/health shows 1.0.3.51

If still failing: backend is not running — check CMD window for errors.
