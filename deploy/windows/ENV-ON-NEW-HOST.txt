=====================================================

This package is HIJRA Bank only. Edit SelfServiceBackend\.env if BC endpoints change.

----------------------------
  CORS_ORIGIN=http://10.30.4.23:4000

Also in SelfServicePortal\server\.env:

  odataBaseUrl => ...
  soapPageBaseUrl => ...
