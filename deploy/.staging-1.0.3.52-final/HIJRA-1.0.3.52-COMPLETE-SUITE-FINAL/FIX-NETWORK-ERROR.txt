NETWORK ERROR ON LOGIN — FIXED IN v1.0.3.52
===========================================

Cause: Old builds called http://localhost:4000 while you open http://10.30.4.23:4000.

This FINAL zip uses on-prem build (no localhost in bundle).

If you still see Network Error after deploy:
1. Ctrl+F5 hard refresh
2. F12 Console:
   localStorage.setItem('ssp.apiBaseUrl', window.location.origin)
3. Check http://10.30.4.23:4000/api/health — must load JSON
4. If health fails → backend not running → START-HIJRA-PORTAL.bat
