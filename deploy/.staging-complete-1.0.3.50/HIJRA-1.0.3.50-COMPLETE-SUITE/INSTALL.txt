-----------------------------------------
1. Stop the running portal/backend service
2. Backup C:\TA\SelfServiceSuite
3. Replace SelfServiceBackend\dist\ and SelfServiceBackend\public\
4. Keep your existing .env — do NOT overwrite
5. Start with START-HIJRA-PORTAL.bat
6. Run VERIFY-DEPLOY.bat
7. Confirm: http://SERVER:4000/api/health shows v1.0.3.50
8. Browser hard refresh: Ctrl+F5
