PATCH 3 — ImprestSurrenderHeader (StaffPortalCodeunit.Codeunit.al)
==================================================================

created/updated and imprestIssueDocNo is known, BEFORE returning docNo:

PATCH 5 — PortalEmployeeDataMgt.Codeunit.al (CuPortalEmployeeData.GetLeaveBalance)
==================================================================================

Replace the entire GetLeaveBalance procedure with PortalEmployeeDataMgt.Codeunit.al
from this folder.

This computes currentLeaveBalance using the EXACT same HR Leave Allocation sums as
HRLeaveApplication.field(4;"Days Applied").OnValidate:

  Current Leave Balance = (Allocated Days + Reimbursed Days) − Current Total Leave Taken

filtered by the active leave calendar code — NOT setup-day entitlement guessing.

JSON fields returned (portal v1.0.3.49 reads these verbatim):
  currentLeaveBalance, allocatedDays, reimbursedDays, currentTotalLeaveTaken,
  activeCalendarCode, isAnnualLeave, cardAnnualLeaveBalance, setupDays, unlimitedDays

for portal fallback when SOAP is temporarily unavailable.
